# Limpieza de descripciones introductorias

Se removieron visualmente las descripciones repetidas que aparecían debajo
del encabezado de las páginas del panel administrativo. La fila introductoria
se colapsa para que el contenido suba y no quede un espacio en blanco.

Las acciones que pudieran compartir esa fila se conservan, y los campos o
columnas de formularios que usan la palabra “Descripción” no se modifican.
