# Ajuste de espaciado del panel principal

Se compactó exclusivamente el dashboard principal para que las tarjetas
queden prácticamente contiguas y el tablero completo entre en una ventana
de notebook sin scroll vertical.

- Separación entre tarjetas reducida a 4 px.
- Padding exterior y margen inferior del encabezado reducidos.
- Padding y separación interna de las tarjetas reducidos.
- Alturas mínimas de las cuatro franjas ajustadas para aprovechar mejor el
  alto disponible.
- Los recuadros internos del dashboard también usan separación de 4 px.
- La versión mobile conserva su scroll natural y sus reglas responsive.
