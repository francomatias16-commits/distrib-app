# Programa de fidelización: puntos y recompensas

## Cómo se ganan puntos

Cada empresa configura cuántos puntos se acreditan por cada peso comprado. Los clientes con mejor categoría de score pueden recibir un **bonus extra de puntos** sobre esa base (por ejemplo, un cliente premium podría ganar un porcentaje adicional).

Los puntos se acreditan automáticamente al confirmarse un pedido, y quedan registrados como un movimiento de puntos con su motivo.

## Saldo de puntos

Cada cliente tiene un saldo con puntos disponibles, puntos ya canjeados y el total histórico acumulado.

## Recompensas y canjes

1. El admin define recompensas disponibles (por ejemplo, un producto gratis o un descuento), con el costo en puntos requerido para canjearlas y, si corresponde, un stock limitado de la recompensa.
2. El cliente canjea una recompensa si tiene puntos suficientes — el sistema exige un mínimo de puntos configurado para poder canjear.
3. El canje puede aplicarse directamente sobre un pedido (por ejemplo, un descuento que se refleja en ese pedido puntual).

## Preguntas frecuentes

**¿Los puntos vencen?**
Depende de la configuración del programa de fidelización de tu empresa — consultá con el admin si tu programa tiene vencimiento de puntos.

**¿Se pueden perder puntos ya ganados?**
Sí, por ejemplo si se anula el pedido que los generó, o al canjear una recompensa (se descuentan del saldo disponible).

**¿Todos los clientes participan del programa automáticamente?**
Sí, mientras el programa de fidelización de la empresa esté activo, todos
los clientes acumulan puntos automáticamente con sus **pedidos** (carrito
del portal/app, o pedido cargado por un vendedor/admin). Las ventas de
mostrador (punto de venta / caja) no acreditan puntos por el momento,
aunque la venta esté asociada a un cliente identificado.
