Formato de la etiqueta

Ancho, alto y márgenes del rollo o de la hoja troquelada que usás para imprimir.

Para hojas troqueladas tipo Avery en A4/carta. No aplica a rollo continuo.

Código de barras

Qué formato de código usar al generar las etiquetas.

Automático: usa EAN-13 real si el producto lo tiene, código de balanza si se vende por peso, y CODE128 con el código interno en el resto. Forzá una opción solo para casos particulares (ej. EAN de 12 dígitos UPC-A).

Contenido de la etiqueta

Qué precio y qué datos extra se imprimen en cada etiqueta.

Mostrar el código en textoDebajo de las barras, por si el lector falla o hay que tipearlo a mano.
Mostrar precio promocional tachadoCuando el producto tiene una oferta vigente en Descuentos automáticos.
